# ClaudeSpotlight Features

## ✨ Key Features

### 🎯 Spotlight-Style Interface
- Floating window that appears on demand
- Clean, minimal design inspired by macOS Spotlight
- Backdrop blur effect for elegant transparency
- Auto-focus on input field for immediate typing

### 🧠 Claude AI Integration
- Powered by Claude 3.5 Sonnet (latest model)
- Real-time streaming responses
- Code generation and explanation
- Natural conversation interface
- Full context awareness

### ⌨️ Keyboard-First Design
- **Global shortcut**: ⌘⇧Space (Command+Shift+Space)
- **Send message**: Enter/Return
- **Close window**: Click outside or ESC
- Always-accessible from any app

### 💬 Chat Interface
- Conversation history within session
- User and assistant message bubbles
- Syntax highlighting for code (planned)
- Copy responses with text selection
- Scrollable history for long conversations

### 🚀 System Integration
- **Menu bar icon**: Quick access from system tray
- **Launch at login**: Automatically starts with macOS
- **Background operation**: Runs as menu bar app (no dock icon)
- **Low memory footprint**: Efficient resource usage

### 🎨 Native macOS Experience
- SwiftUI for modern, native UI
- NSVisualEffectView for blur effects
- System color scheme integration
- Smooth animations and transitions
- Respects system appearance (Dark/Light mode)
